# Игровые ассеты

Здесь храним оригинальные изображения, спрайты и аудио, используемые игрой. У внешних материалов фиксируем источник и лицензию. Большие исходники перед добавлением оцениваем на необходимость Git LFS.

Текущая стоянка рисуется геометрическими примитивами в `src/game/CampScene.ts` и служит временной графикой. Финальные пиксельные ассеты ещё не созданы.
