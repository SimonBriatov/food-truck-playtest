# Combat sound effects

These seven MP3 files are selected from [Kenney RPG Audio](https://kenney.nl/assets/rpg-audio) and [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds). Both packs are released under [Creative Commons Zero (CC0)](https://creativecommons.org/publicdomain/zero/1.0/), including commercial use; credit is appreciated but not required.

`knifeSlice`, `knifeSlice2`, and `chop` come from RPG Audio. `impactPunch_medium_000`, `impactPunch_heavy_000`, `impactMetal_medium_000`, and `impactBell_heavy_000` come from Impact Sounds. The source OGG files were transcoded to MP3 for broad mobile browser support. No other edits were made.
